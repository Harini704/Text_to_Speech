# Python Text-to-Speech Converter

This project converts text into speech using the Google Text-to-Speech (gTTS) library. The generated speech is saved as an MP3 file and can be played on any device that supports audio playback.

## Features

* Convert text to speech
* Generate MP3 audio files
* Fast and easy to use
* Supports multiple languages
* Built with Python and gTTS

## Requirements

* Python 3.x
* gTTS library

## Installation

pip install gtts

## Usage

1. Enter the text you want to convert.
2. Run the Python script.
3. The generated audio will be saved as `sample.mp3`.

## Example

This project converts the story "The Lion and the Mouse" into an MP3 audio file.
